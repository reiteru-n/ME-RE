営業アクション分析

SlackとOutlookの送受信ログから、営業メンバーごとの行動量・顧客接点・成果への転換を週次で集計します。量を見て、効率を比べ、振り返りで次の一手を決めるためのページです。

サンプルデータ（架空のメンバー）

週次アクション量

社外メール送信とSlack投稿の件数

成果につながる行動

商談・提案・見積の週次件数

効率マップ

横：週あたりアクション量 ／ 縦：100アクションあたりの商談・提案・見積

活動時間帯

曜日×時刻ごとのアクション件数（6時〜23時）

行動ファネル

期間内の件数と、ひとつ前の段階からの比率

チャネル別の内訳

顧客向けの行動と社内向けの行動の比率

メンバー別スコアカード

行をクリックするとそのメンバーで全体を絞り込みます。見出しで並べ替え。

今期の気づき

前の期間とチーム平均を比べて自動で抽出

    振り返りメモ（KPT）

    週次1on1・チーム会で使う下書き

    実データの取り込み方法と指標の定義
    1. 収集：リポジトリの sales-activity/collector/ で Slack と Outlook（Microsoft Graph）からメタデータのみを取得します。本文は保存しません。 
      python collector/slack_collector.py   --config config.json --since 2026-07-01
python collector/outlook_collector.py --config config.json --since 2026-07-01
python collector/aggregate.py         --config config.json --out data/activity.json
    2. 読み込み：上の「集計データを読み込む」で data/activity.json を選びます。ファイルはこのブラウザ内でだけ処理され、どこにも送信されません。
    3. 指標：アクション＝社外メール送信＋Slack投稿。社外比率＝（社外メール＋案件チャンネル投稿）÷アクション。返信時間＝顧客からのメール受信から同スレッドの初回返信までの分数。時間外＝平日9時前・18時以降と土日。商談・提案・見積はカレンダー招待と件名・投稿のキーワード分類で判定します。

    個人の行動データを扱うため、評価・査定の直接材料にはせず、本人と上長の振り返りと業務改善のために使う前提で設計しています。運用前に対象メンバーへの説明と同意取得を行ってください。
